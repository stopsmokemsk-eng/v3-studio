# V3 / Orbital Mechanics

Original 80-second stereo ambient loop for V3 Studio, created from synthesized signals and noise. No samples, melody or audio from SOLIPSIST are included. The reference excerpt was not available for listening. The revised sound uses clear major harmonies, rounded mid-register pulses, airy stereo reflections and quiet printer-axis-style micro-movements rather than low drones or metal creaks.

Active file: `v3-soft-circuit.mp3`. MP3: 44.1 kHz, stereo, 128 kbps. Quiet master targeted at approximately -24 LUFS, with additional browser-level attenuation where supported. Fixed-gain mastering preserves the periodic synthesized loop.

Playback is optional and begins only after user interaction. Consent appears on first entrance to the main menu, not on the installation page or introduction. The isolated studio-sound module owns consent, its media element, the persistent corner button and temporary suspension during audible video. A saved choice is kept locally on the device.

Administrators can replace the soundtrack from Personal Account. Supported browser-decodable audio files up to 50 MB are checked before replacement and stored in the existing local IndexedDB media store. Only a small reference and filename are kept in localStorage. Reload restores the selected file, without changing the visitor's music on/off preference. Invalid files leave the previous track intact; resetting restores the bundled track and releases the previous custom file. This is device/browser-local, not a global site update.
