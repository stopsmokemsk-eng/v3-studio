# Game brand marks

These monochrome marks identify fictional computer-controlled opponents, not studio partners or endorsements.

Downloaded from [Simple Icons](https://github.com/simple-icons/simple-icons), npm version 13.21.0. The accompanying LICENSE.md contains the project license. Brand trademarks remain the property of their respective owners.

The game draws the SVG paths in monochrome and retains brand text as a fallback if an asset cannot load.
